# Gold Gym Kumbakonam Website

Premium animated gym website built with React + TypeScript + Vite + Tailwind CSS + Framer Motion + GSAP.

## How to run (English)

1. Install Node.js 20+.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```
4. Open the shown URL (usually `http://localhost:5173`).

## Editable business data

All business placeholders are in:

- `src/data/siteData.ts`

You can update phone, email, address, WhatsApp link, map link, trainers, plans, testimonials, and counters from that single file.
